# Global Soil Explorer: Keyboard Shortcuts Specification

This document defines the keyboard shortcut matrix to ensure fast power-user exploration.

---

## 1. Application-Wide Shortcuts

| Key Combination | Action | Scope | Purpose |
| :--- | :--- | :--- | :--- |
| `Ctrl + /` | Toggle Help Overlay | Global | Displays modal listing all shortcuts |
| `Ctrl + K` / `/` | Focus Search Input | Global | Focuses the search/autocomplete field |
| `Esc` | Clear Active Action | Global | Closes modals, clears active search suggestions |
| `[ / ]` | Toggle Sidebar | Global | Collapses or expands the Layer Manager sidebar |
| `\` (Backslash) | Toggle Info Panel | Global | Collapses or expands the Scientific Panel |

---

## 2. Map Canvas Shortcuts

*   `+` (Plus) / `=` (Equals): Zoom in by 1 level.
*   `-` (Minus): Zoom out by 1 level.
*   `Arrow Up / Down / Left / Right`: Pan map viewport box by 100px.
*   `H` (Home): Reset camera center and zoom bounds to the active Study Area default configuration.
*   `R` (Reset): Reset bearing to true north and pitch to zero.
*   `F` (Fullscreen): Toggle full-window view modes.

---

## 3. Scientific Workspace Shortcuts

*   `Ctrl + S`: Bookmarks the active coordinate selection.
*   `Ctrl + E`: Opens the Export Options drawer.
*   `1`, `2`, `3`, `4`: Toggle tabs in the Scientific Panel:
    *   `1`: Summary tab
    *   `2`: Profiles tab
    *   `3`: Physical / Chemical property charts tab
    *   `4`: Export configurations tab
