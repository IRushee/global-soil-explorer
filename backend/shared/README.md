# Shared Module

## Purpose
Provide common, domain-agnostic helpers across the codebase.

## Responsibilities
*   Define global constant values.
*   Abstract logging handlers.
*   Host common mathematical formulas.

## Allowed Contents
*   Pure utility functions
*   Mathematics
*   Logging
*   Constants
*   Exceptions

## Forbidden Contents
*   Business logic
*   Domain logic
*   Repository implementations
*   Services
