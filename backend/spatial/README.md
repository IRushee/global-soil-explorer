# Spatial Lookup Module

## Purpose
Resolve geographical coordinates to spatial mapping unit keys.

## Responsibilities
*   Convert GPS coordinates to grid row and column offsets.
*   Extract mapping unit indices from binary spatial grids.

## Allowed Contents
*   Coordinate translation calculations
*   Binary grid file stream seek utilities
*   Raster layout metadata descriptors

## Forbidden Contents
*   Domain profiles and business logic
*   Database tables and attributes querying
*   API request routing
