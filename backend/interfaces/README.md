# Interfaces Module

## Purpose
Provide entry points into the application.

## Responsibilities
*   Intercept client commands and web requests.
*   Forward execution commands to the Orchestration Layer.
*   Format output responses.

## Allowed Contents
*   Web server routers
*   CLI adapters
*   Batch run controllers
*   AI communication adapters

## Forbidden Contents
*   Business workflows
*   Database connections
*   Direct spatial lookup calculations
