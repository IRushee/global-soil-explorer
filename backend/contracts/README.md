# Contracts Module

## Purpose
Hold contracts and data schemas exchanged between backend layers.

## Responsibilities
*   Define standardized structures for input and output operations.
*   Abstract communication interfaces between modules.

## Allowed Contents
*   Boundary Models (Request models, Response models)
*   Repository contracts
*   Shared interfaces

## Forbidden Contents
*   Scientific domain validation rules
*   Database query execution logic
*   Core business workflows
