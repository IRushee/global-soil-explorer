# Application Services Module

## Purpose
Coordinate business workflows and orchestrate internal subsystems.

## Responsibilities
*   Manage transaction boundaries.
*   Enforce process orchestration rules.
*   Execute use-case workflows.

## Allowed Contents
*   Orchestration services
*   Workflow managers
*   Transaction boundary controllers

## Forbidden Contents
*   HTTP routing
*   Serialization codecs
*   API request validators
*   Database connections
*   Direct spatial lookup seeking math
